这套学习顺序怎么来的

  1. 先学平假名，熟练后再学片假名。片假名多数和平假名同源，学的时候对照平假名记。
  2. 一次只学一行（5 个左右）。每个字先听音，再看它的“图像联想”，把字形和读音绑在一起。这是日本国际交流基金 Memory Hint 教材和 Tofugu 指南共同采用的方法。
  3. 看懂字源。假名由汉字草书（平假名）或汉字偏旁（片假名）演变而来，中文母语者看字源记得更快。
  4. 学完一行马上自测，并混入前几行的字。主动回忆比反复看表格更有效。
  5. 读得出来以后再练书写，按笔顺描红，再默写。
  6. 之后交给“复习”页的间隔重复：答对的字隔得越来越久才出现，答错的字马上回到第一盒。

间隔重复（莱特纳盒子）

每个假名（平、片分开计）都在一个盒子里。答对就进下一盒，下次出现的间隔变长；答错回到第 1 盒，当天再练。每天把“到期”的字过一遍即可。

易混字对照

这些字形状接近，初学时最容易混。点一组卡片，只用这组字出题。
